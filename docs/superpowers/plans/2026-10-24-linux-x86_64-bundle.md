# Ubuntu x86_64 温控与目录包实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 Ubuntu 26.04 x86_64 上读取可信 CPU Package 温度、运行现有最爱档控制，并生成无需目标机 Python 的可迁移目录包。

**架构：** Linux 传感器只读取 `coretemp` 的 `Package id N` 毫摄氏度值；配置和 CLI 将 `linux` 分派给它。Runner 在首次有效温度前禁止设备写入。构建器在 Linux x86_64 原生环境用 PyInstaller 单目录打包，生成 `check.sh`/`run.sh`，保留现有公开模板与密钥隔离规则。

**技术栈：** Python 3.11、`unittest`、`python-miio==0.5.12`、PyInstaller 6.x、Linux `hwmon`、Ubuntu 26.04 x86_64、Docker（仅构建隔离环境）。

- [ ] **步骤 3：最小实现。** 用 `Path("/sys/class/hwmon")` 作为生产默认根目录并允许测试注入根目录；对每个 `hwmon*` 读取 `name`，只接受 `coretemp`，对 `temp*_label` 使用 `re.fullmatch(r"Package id [0-9]+", label)`，读取配套 `_input` 的整数毫摄氏度值并经 `_valid_temperature(raw / 1000)` 校验；任一匹配值坏掉即报 `SensorError`，否则返回最大值。配置允许 `linux` 且必须与 `sys.platform` 匹配；CLI 在 Linux 分支直接创建该读取器，其他分支不变。

  ```python
  class LinuxTemperatureSource:
      def __init__(self, hwmon_root: Path = Path("/sys/class/hwmon")) -> None:
          self._root = hwmon_root

      def read(self) -> float:
          values = []
          for hwmon in self._root.glob("hwmon*"):
              if (hwmon / "name").read_text().strip() != "coretemp":
                  continue
              for label_path in hwmon.glob("temp*_label"):
                  if re.fullmatch(r"Package id [0-9]+", label_path.read_text().strip()):
                      input_path = label_path.with_name(label_path.name.replace("_label", "_input"))
                      values.append(_valid_temperature(int(input_path.read_text()) / 1000))
          if not values:
              raise SensorError("CPU Package temperature is unavailable")
          return max(values)
  ```

  将以上文件读写和转换异常统一捕获并转为不包含原始路径/内容的 `SensorError`；不得吞掉已发现 Package 的异常继续返回其他 Package 的温度。
